# fuzzy-diffusion (en-version)
In this repository, I will develop a diffusion model to create a sinthetic dataset in order to data augment RFMID 2.0 to increase performance in a classifier. Lastly but not least :D, I'll incorporate a fuzzy mechanism in order to make the threshold dynamic for the classifier. 

# difusión difusa (versión en español)
En el presente repositorio, se desarrollará un modelo difuso para crear una dataset sintético con el objetivo de mejorar el rendimiento de un modelo de clasificación multi-etiqueta. Asimismo, se creará un modelo de fuzzy logic para mejorar la explicabilidad y, también, la eficacia del modelo de clasificación.
